# Karma magic purchases and completion

The Karma foundation now quotes source-bound traditions/streams, supported
spells, complex forms and undiscounted adept powers. Core derives chooser
capabilities from the purchased talent and confirmed skill unlock. Profile
prices fund spells/forms and Mystic Adept power points; Priority free grants
are never borrowed. Unsupported payloads remain disabled with reasons.

The optional magic selection is part of the existing revision-bound pending
decision. Confirming that draft does not apply character XML. A separate,
explicit finalization applies talent grants, selected magic, costs and Career
carryover once and archives the original pending decisions. Source changes
between review and commit fail closed. Historical decisions with absent magic
fields retain their original serialization.

Local .NET 10.0.103 verification on 2026-09-21: 34 focused catalog, pricing,
selection, persistence and finalization cases passed. Coverage includes Mage,
Mystic Adept, Adept and Technomancer cold completion/replay, Aspected access,
combined contacts/lifestyle spending, source drift and malformed retained
history. The shared legacy helper also passed the existing selected Priority
and Mystic Adept finalization cases; an earlier Karma Custom-tradition failure
was corrected by rejecting incomplete source payloads at selection time.

This is implementation evidence, not an Android device or publication receipt.
The Android wizard integration, affected device save/reopen/restart smoke and
the new package recipe remain separate work. Preview26 is unchanged. Custom
